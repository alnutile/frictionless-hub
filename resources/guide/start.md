Frictionless Hub walks a team through a developer-experience (DevEx) program, one activity at a time.

**How it's organized**

- An **initiative** is one program for one org, business unit, or team. Everything you capture belongs to an initiative.
- Each initiative moves through **phases**: Discover → Quick wins → Data → Prioritize → Sell → Implement & report.
- Each phase has **activities**. Do them roughly in order, since later activities build on what earlier ones capture.

**Roles**

- **Admins** manage users, edit this guide, and can change any initiative.
- **Facilitators** create and run their own initiatives.
- **Viewers** can read everything and add their own ratings.

**Using the guide**

Open this panel on any screen to see what the activity is for, how to use it, and what to watch out for. The notes box at the bottom is private to the initiative. Use it to record decisions, open questions, and reflections as you go.
